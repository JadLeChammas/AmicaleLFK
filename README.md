# Amicale LFK 🎉

Bienvenue sur le dépôt GitHub de **l'Amicale LFK** — la plateforme centrale de gestion, de partage et de communication pour les activités associatives de la communauté LFK 🎓🇫🇷🇰🇼

---

## 📁 Structure du projet

- `css/` : Feuilles de style pour l'interface utilisateur
- `img/` : Ressources visuelles (logos, bannières, etc.)
- `js/` : Scripts JavaScript utilisés dans le front-end
- `logs/` : Dossiers de logs (à restreindre dans le .gitignore si sensible)
- `uploads-proof/` : Preuves ou fichiers envoyés par les membres

---

## 🚀 Objectif

Ce projet vise à :
- Centraliser les activités de l'amicale
- Permettre aux membres de soumettre des documents (adhésion, justificatifs, etc.)
- Offrir un espace moderne, visuel et intuitif pour la communication associative

---

## 🛠️ Technologies utilisées

- HTML/CSS/JavaScript
- PHP (Backend)
- MySQL (Base de données)
- Git / GitHub pour le versioning
